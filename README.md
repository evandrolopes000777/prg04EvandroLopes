# Sistema de Gestão de Academia - Interface Web

Este projeto abriga a interface web para o Sistema de Gestão de Academia, com o objetivo de substituir o controle manual por uma solução digital completa

## 🎯 Funcionalidades

* **Autenticação de Usuários:** Telas de login para acesso ao sistema

* **Gestão de Alunos:** Telas para cadastrar, listar, buscar e editar os dados dos alunos

* **Controle de Planos e Pagamentos:** Interface para vinculação de planos ativos e registro de pagamentos

* **Fichas de Treino:** Telas para criação e visualização das séries, repetições e cargas de exercícios

O layout e as permissões de acesso serão divididos entre dois atores principais: o Administrador, que possui acesso total aos cadastros, pagamentos e treinos e o Aluno, que visualizará sua própria ficha de treino e a situação do seu plano

## 🗂️ Estrutura inicial do Projeto 

* 📄 **`index.html`**: O arquivo principal e ponto de entrada da aplicação.

* 📄 **`atividade-03.html`**: Página contendo a lista de exercícios e carregamento de imagens responsivas.

* 📄 **`cores.html`**: Página de demonstração da paleta de cores e design do projeto.

* 📄 **`sandbox.html`**: pagina utilizada para testar os conceitos aprendidos.

* 📁 **`assets/`**: Pasta principal contendo os recursos estáticos da aplicação.
  * 📁 **`audio/`**: Pasta contendo os audios da aplicação.
  * 📁 **`css/`**: Pasta criada para armazenar as folhas de estilo.
  * 📁 **`icons/`**: Ícone (favicon) de identificação da aplicação que é exibido na aba do navegador.
  * 📁 **`images/`**: Pasta contendo as imagens da aplicação, subdividida em `background` e `imagens-dinamicas`.

*(A pasta `js` será incluída na estrutura nas próximas etapas, aguardando a inclusão dos scripts).*

A estrutura atual mudará consideravelmente ao longo do desenvolvimento. O repositório será expandido para suportar os requisitos funcionais do sistema
